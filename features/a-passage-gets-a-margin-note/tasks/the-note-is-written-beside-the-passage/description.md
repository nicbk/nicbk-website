# Task: The Note Is Written Beside the Passage

Task 1 of 2 of [#28](../../description.md). Sub-issue [#243](https://github.com/nicbk/nicbk-website/issues/243).

*margin note* on the selection menu. It highlights the passage and creates a text box
in reply to the highlight, flagged `locked`, in the nearer margin and level with
the passage, open for typing. It refuses, with a reason, when the spot overlaps
any annotation or the margin is too narrow. Deleting the highlight takes the
note with it, and an empty note is removed when editing ends.
