# Task: The Folds Are Kept

Task 2 of 2 of [#30](../../description.md). Sub-issue: not yet created.

The open set moves from page state to the account, so a paper's contents reopen
as they were left, on any device.

## Changes

- **`src/db/schema/lit-tracker.ts`**: `article_contents.expanded`, a `jsonb`
  `number[]`, default `[]`, not null. Its comment says why it lives on this
  table and not on `articles` (research §3).
- **A migration**, generated by Drizzle and applied from the committed files.
  The table is already in the `zero_data` publication.
- **The Zero schema** is regenerated (`src/zero/schema.gen.ts`).
- **`articleContents.setExpanded({ articleId, index, open })`** in the
  mutators. It is modelled on `articles.setReadingPosition`:
  - owner only;
  - an index must fall within `entries`;
  - it adds or removes one index;
  - it leaves `updated_at` alone.
- **`extract-stage.ts`**: the upload's `onConflictDoUpdate` also sets
  `expanded: []`.
- **The panel's open set** comes from the synced row through
  `use-article-contents.ts`. Pressing a chevron calls the mutator; the local
  update shows it at once.
